# Cliploom 2.0.0-preview.2

这是 Windows 10/11 x64 测试版，供现有用户验收 2.0 内容工作台。安装包未签名，未内置 Whisper 模型，也未加入 VC++ x64 运行库自动安装脚本。

## 下载与核对

- [下载安装包](https://github.com/LaowtZhou/Cliploom/releases/download/v2.0.0-preview.2/Cliploom-2.0.0-preview.2-setup.exe)
- 文件名：`Cliploom-2.0.0-preview.2-setup.exe`
- SHA-256：`32C73CE4F0F851C7618B858E53125BEA6DC7FF0647804673800C719D69F6FEF0`

安装前完全退出旧版，并备份当前内容库。安装包会沿用当前 Windows 用户的应用数据；首次测试建议使用隔离的内容库。Windows 显示“未知发布者”时，应先核对下载地址和 SHA-256。

## 本轮改进

- 在“视频”中点击“添加并下载”后，新视频立即进入解析和下载队列，不再要求第二次手动启动。已有暂停任务不会因此一起启动。
- 下载完成且“自动转写”开启时，视频自动进入转写队列；数据库短暂繁忙时队列会等待并重试，避免工作线程永久退出。
- 2.0 工作台继续完善 Markdown 创作稿、知识库文件树、标签和属性索引、文章归档与多标签编辑体验。

## 安装后验收

1. 确认软件版本为 `2.0.0-preview.2`，在设置中确认“自动转写”已开启。
2. 添加一条已获授权的测试视频，点击“添加并下载”；观察该条任务立即显示“解析中”或“下载中”，无需再次点开始。
3. 下载完成后，观察同一视频进入“等待转写”或“转写中”；模型首次下载和加载可能耗时。完成后打开 TXT/SRT 核对内容。
4. 检查旧版留下的“等待转写”任务在升级后继续处理；重复添加同一未完成链接不会产生两个同时下载的任务。
5. 若出错，保留任务状态、错误提示和截图，通过仓库 Issue 反馈；不要上传视频、文章、数据库、登录凭据或 API 令牌。

开发侧已通过桌面端 162 项、内容服务 160 项测试，以及类型检查、UI 契约、生产构建、内容服务独立启动和 NSIS 打包检查。`preview.2` 在用户真实账号上的安装、真实视频下载和 Whisper 转写仍需人工验收。“数字生命卡兹克”历史同步额度错误仍是已知问题。
